# 叫び声の定義(オリジナル)
- 比較的様式化の程度が低く，非語彙的な感情表出系感動詞
- 語彙的だったら感動詞
  - ↑これはちょっと違う。感情表出系感動詞はそもそも語彙的でない(「あ」「え」「うわ」など)。
ただ、「え」などは辞書にも載っているなど、比較的様式化されているものもある。様式化の程度は、
叫び＜叫び以外の感情表出系感動詞＜語彙的発話、の順

# 叫び声の範囲を狭めるための要件
オリジナルの定義だと、一般的に叫び声だとみなされないものまで含んでしまい不都合があった。
- screamに、「大きく聞こえる」という要件を追加
- {s}と{a}以外だと思うものは{o}とする。
  - G008_1_R 037 {o 短い断片}
  - G001L utterance552 {o うめき声}
- 「うわ」「うお」「わ」は辞書に載っていない様式化されていない単語。でも，日本語の口語的には様式化されている。恣意性があるかないか。これはscream。
# shout
オリジナルにはなかったshoutというカテゴリを追加した。
- 語彙的な音声で叫んでいる
# scream
- 非語彙的な音声で叫んでいる
# 新しいaffect burst分類スキーム (2022千葉工大改訂版)
- 隣接ペアを構成しない。他者への呼びかけ・応答の役割を持たない。
- {a}...感情表出系感動詞の中でも ~~書き起こしが容易で~~ 様式化の程度が高いもの(例 「あ」「え」「お」「は」「ん」など)
- {s}...感情表出系感動詞の中でも様式化の程度が低く書き起こしが難しく音量が大きいもの(例 「あぁぁぁ」など)
- {shout}...{s}とは異なり，様式化の程度が高く書きおこしが容易で，音量が大きいもの(例 「なんでぇぇ」など)
- {o xxx}...{a}や{s}や{shout}のどれかにあたるが音量が小さいなどの定義が合わないもの(xxxには具体的な内容を入れる)

[白鳥・松田・有本](https://clrd.ninjal.ac.jp/lrw/lrw2022/p4-8s_paper.pdf) (言語資源活用ワークショップ2022)には、
{s}と{shout}の定義に「韻律あるいは声質が特異なもの」とある一方、{o}の説明に「音量が小さいなどの定義に合わないもの」とある。
「韻律あるいは声質が特異なもの」と「音量が大きい」は同義ではないので、見直しが必要。
